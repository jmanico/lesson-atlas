# LessonAtlas

LessonAtlas is a web and API application for teachers to organize student information, prepare standards-aligned lessons, identify support needs, plan small groups, and manage classroom schedules. AI assists with drafting and analysis; teachers control every accepted change.

## Specification ownership

| File | Domain and when to read |
| --- | --- |
| [REQUIREMENTS.md](REQUIREMENTS.md) | WHAT the system does; read before changing observable behavior. |
| [DESIGN.md](DESIGN.md) | Design language; `style-guide.html` is its rendered reference. Read before UI work. |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Components, boundaries, data flow, and dependency rules; read before structural changes. |
| [SECURITY.md](SECURITY.md) | Security rules and threat model; read before touching auth, input handling, data protection, or any trust boundary. |
| [REQUIREMENT_TEMPLATE.md](REQUIREMENT_TEMPLATE.md) | Required structure for new GitHub issues; read before creating an issue. |

Every new GitHub issue MUST follow `REQUIREMENT_TEMPLATE.md` so each issue is a structured, testable requirement.
